# Aaron Barbosa portfolio refresh

This folder contains replacement versions of the six code files in the existing GitHub Pages repository:

- `index.html`
- `style.css`
- `script.js`
- `photo.html`
- `style2.css`
- `script2.js`

The existing `your-picture.jpg`, `GM.png`, and `photos/` folder are still used. The two image files are included here only so this folder can be previewed on its own; you do not need to replace the originals unless desired.

## Publish

1. Copy the six updated code files into the root of `AaronMBarbosa.github.io`.
2. Commit and push to the `main` branch.
3. GitHub Pages should redeploy automatically.

## Local preview

Run a basic local web server in this folder, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
